# 0.8.1 验证记录

- Mac 原生 Swift 程序编译成功，应用临时签名通过 deep / strict 校验。本机默认 SDK 27 与编译器版本不匹配，使用已安装的兼容 SDK 26.5 完成构建；其他机器可通过 SDKROOT 指定与本机编译器匹配的 SDK。
- Mac 原生角色测试通过：形状/颜色/图片格式校验、独立文件持久化与读回、JSON 导入导出、不包含聊天数据。
- 使用真实 PNG 完成 JavaScript → Swift → JavaScript 角色文件往返，图片和设计参数保留。
- Windows 模型与模拟 Electron 主进程测试通过：情绪恢复、喂食、亲密度、成长、存档、学习整组拖动及结束条件、六种游戏、提醒、IPC 权限与密钥隔离。
- 角色编辑的 JSON 文件导入/导出实际读写、性格变更、存档读回及不携带聊天测试通过。
- 真实 Canvas 渲染 6,480 帧：三种身体 × 三种头顶 × 两种眼睛 × 两种成长阶段 × 全部动作 × 12 时刻，包括换装和方向变化，边缘未被裁切。
- 自定义更新协议的签名、篡改、旧版本、非 HTTPS 及不兼容运行环境拒绝测试通过。
- Mac / Windows 同版本更新包生成通过，源程序、公钥和版本一致。发布后补充完成真实公网检查与下载校验，详见 `ONLINE_RELEASE.md`；未执行用户程序的自动替换和重启。
- 内置配乐由 Python 标准库合成，未下载任何外部录音或曲谱；两端均指向本项目内置 WAV。
- 本机存档和设计备份放在公开包之外。公开目录采用白名单打包，排除个人数据和签名私钥，并检查没有旧角色素材/品牌引用。

## 尚未验证

- 当前受限终端启动 GUI 应用时在 macOS 注册应用阶段被终止，原生 UI 与原生学习场景的本轮自动化复测没有完成；纯数据角色测试在初始化 GUI 前执行并通过。
- Chromium UI 自动化脚本已提供，但在本环境启动 Chrome 被系统终止，未取得浏览器交互通过结果。Canvas 绘制测试不是 Windows 桌面实机测试。
- Windows 桌面窗口、透明命中、系统密钥加密、PowerShell 替换/重启尚未在 Windows 电脑实测。
- 导入自绘完整立绘后只进行整体运动与手持物覆盖，没有自动切分图片肢体，也没有图片骨骼编辑功能。
- 未进行真实 API 聊天请求；现有逻辑测试使用模拟服务，不消耗任何 API 额度。

运行基础测试：在仓库根目录执行 `npm test`（基础测试只用 Node 标准库）。可选渲染测试先安装根目录的开发依赖，再执行 `npm run test:render`。UI 测试需 Playwright 支持的浏览器，或设置 CHROME_PATH 后 `npm run test:ui`。
